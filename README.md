# 🚀 Modern Developer Portfolio

A sleek, fully responsive, and interactive personal portfolio website built with modern web technologies. Designed to showcase my technical skills, projects, and professional background as a Computer Science student and developer.

## 🛠️ Tech Stack & Features

- **Framework:** React.js / Next.js (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **UI Components:** Traken UI / Custom Components
- **Features:** 
  - Fully Responsive (Mobile & Desktop friendly)
  - Interactive Project Showcase (featuring DocEase, Book Recommendation, Deepfake Detection, etc.)
  - Tech Stack & Skills Grid
  - Smooth Scrolling & Animations

## 📂 Project Structure

- `src/components/portfolio/` - Contains all portfolio sections (Navbar, Hero, About, Projects, Skills, Contact, Footer)
- `src/pages/` - Main portfolio page wrapper

## 💻 Getting Started

Clone the repository and run it locally:

```bash
git clone [https://github.com/ShivamNishad0/portfolio-main.git](https://github.com/ShivamNishad0/portfolio-main.git)
cd portfolio-main
npm install
npm run dev
